# CRYPTO SENTINEL · 加密貨幣即時監控終端

即時市場監控 + 聰明錢流向 + 訂單簿微結構 + 持倉異常偵測，純前端（零建置、零相依、零金鑰），
直接開 `index.html` 或部署到 GitHub Pages 即可使用。

線上版：<https://yuchen0614.github.io/crypto-sentinel/>

---

## 功能

### 1. 全市場掃描（左欄）
- Binance 現貨全部 USDT 交易對（自動濾除穩定幣、槓桿代幣、成交量 < 20 萬美元者），約 380–420 檔。
- 即時價格（WebSocket 推送逐筆閃動）、24H 漲跌、24H 成交金額、**資金動能分數**。
- 資金動能 ＝ 24H 動能 × 週轉率（量/市值，取自 CoinGecko）× 24H 區間位置 × 資金費率偏向。
- 排序（成交量／漲幅／波動／資金動能）、搜尋、僅合約過濾、市場寬度條。
- 鍵盤：`↑` `↓` 切換幣種、`/` 聚焦搜尋。

### 2. 主圖表（中欄）
- Canvas 自繪 K 線（1m/5m/15m/1H/4H），含成交量、**CVD 累積主動買賣差**、VWAP、掛單牆水平線、巨鯨成交標記。
- 十字準線與逐根 K 線浮動資訊；現價線與右側價格刻度依該交易對 tick 精度顯示。
- 統計條：24H 高/低/量/筆數、VWAP、ATR% 波動率、近 15 分鐘主動買賣差、主力成本帶（Volume Profile 重心 ±1σ）。

### 3. 訂單簿追蹤（中欄）
- Binance 深度快照 **1000 檔**（每 2.2 秒）× WebSocket 20 檔即時盤口，合併成買賣階梯與深度條。
- 買賣不平衡度：近端（1–20 檔）＋中段（21–200 檔）的買賣比與偏離。
- 掛單牆：10 檔之後、金額達同側中位數 5 倍且 ≥ 15 萬美元者，顯示價位、距中價距離、佔該側可見流動性比例。
- **疑似假掛單（快閃牆）**：掛單牆若在 45 秒內出現又消失且規模 ≥ 12 萬美元，判定為疑似 spoofing 並發出事件。

### 4. 深度熱圖（中欄）
- 以「距現價的相對距離」為縱軸、時間為橫軸，把每 2.2 秒的快照堆疊成密度熱圖（對數色階）。
- 深度範圍自適應（例如 BTCUSDT 1000 檔約涵蓋中價 ±0.3%），面板會標示實際涵蓋範圍。
- 掛單重心：全部掛單的金額加權重心相對中價的位置。

### 5. 異常事件偵測（中欄）
分級（HIGH / MED / INFO）並自動去重冷卻，涵蓋：
巨鯨連續掃貨/砸盤、成交量異常放大、價格急漲急跌、買賣掛單嚴重失衡、疑似假掛單、
持倉異常堆積、資金費率極端、清算潮（多殺/空軋）。

### 6. 聰明錢壓力計（右欄）
7 項即時指標加權成 0–100 壓力分數與文字結論，並列出每項指標的貢獻值：

| 指標 | 權重 | 資料來源 |
|---|---|---|
| 巨鯨淨流向（5 分鐘） | 20% | 逐筆成交（現貨 + 合約） |
| CVD 累積斜率 | 18% | 逐筆成交主動買賣差 |
| 大戶部位方向 | 18% | Binance 合約 `topLongShortPositionRatio` |
| 訂單簿買賣壓力 | 14% | 深度快照 |
| 槓桿結構（資金費率＋OI 一致性） | 12% | `premiumIndex` + `openInterestHist` |
| 價格動能（VWAP 與短均線） | 10% | K 線 + 逐筆成交 |
| 清算方向壓力 | 8% | Bybit `allLiquidation` |

分數區間：≥74 強力吸籌／偏多 · 60–73 偏多 · 55–59 微幅偏多 · 46–54 中性觀望 · 41–45 微幅偏空 · 27–40 偏空 · ≤26 強力派發／偏空。

### 7. 巨鯨即時動向（右欄）
- 逐筆大額成交（門檻 5 萬／25 萬／100 萬美元可切換），顯示時間、方向、價位、數量、金額；
  ≥25 萬美元標記為大型、≥100 萬美元標記為巨鯨並有脈衝動畫。
- 1／5／15 分鐘淨流向（大單買 − 大單賣）與方向游標。

### 8. 持倉結構 · 異常偵測（右欄）
未平倉量與 1H 變化、資金費率與年化、大戶持倉多空比、大戶帳戶比、散戶帳戶比、主動買賣比，
以及 OI 走勢圖；下方自動生成訊號卡：持倉異常堆積、價漲量增、價跌減倉、大戶散戶方向分歧、
主動買盤/賣盤背離、資金費率極端等。

### 9. 爆倉清算流（右欄）
Bybit 線性合約全市場清算事件（涵蓋成交量前 100 個幣種），顯示近 1 分鐘／15 分鐘清算金額、
多空比與逐筆清單；1 分鐘內清算 ≥150 萬美元時觸發清算潮事件。

## 資料來源（全部為公開端點，無需 API 金鑰）

| 用途 | 端點 |
|---|---|
| 現貨行情、K 線、深度 | `api.binance.com` REST |
| 現貨逐筆成交、20 檔盤口、全市場輕量行情 | `wss://stream.binance.com:9443` |
| 合約統計（資金費率、持倉、大戶多空比、OI） | `fapi.binance.com` REST |
| 合約逐筆成交、清算事件 | `wss://stream.bybit.com/v5/public/linear` |
| 市值、週轉率、BTC 市佔 | `api.coingecko.com` |
| 恐懼貪婪指數 | `api.alternative.me` |

> **為什麼合約走 Bybit？** Binance 合約串流 `fstream.binance.com` 在部分網路環境可以完成
> 連線交握卻不會推送任何資料（靜默封鎖），因此合約成交與清算改用 Bybit 公開串流；
> 合約的資金費率、持倉與大戶多空比仍取自 Binance 公開 REST（可用）。
> 所有串流都有指數退避重連與 90 秒心跳看門狗，現貨串流失敗時會自動切到 Bybit 現貨備援。

## 檔案結構

```
index.html              版面（HUD、三欄主體、狀態列）
assets/css/main.css     科幻風主題、動畫、響應式
assets/css/fonts.css    內嵌字型（Orbitron / Rajdhani / Share Tech Mono，離線可用）
assets/fonts/*.woff2
js/util.js              格式化、統計、事件匯流排、sparkline
js/api.js               REST 資料層（容錯、快取、備援）
js/stream.js            WebSocket 管理（重連、看門狗、多來源）
js/analytics.js         量化核心：成交流、訂單簿、持倉、清算、壓力分數、異常偵測
js/chart.js             Canvas 繪圖：主圖表、深度熱圖、壓力計、OI 走勢
js/book.js              訂單簿 DOM 渲染
js/ui.js                掃描表、巨鯨、清算、持倉、事件面板
js/app.js               啟動流程、事件編排、定時任務
```

## 本機執行

```bash
python -m http.server 8777
# 開啟 http://127.0.0.1:8777/
```

直接雙擊 `index.html` 也能跑（全部使用傳統 script，沒有 ES module 或 fetch 本機檔案）。
