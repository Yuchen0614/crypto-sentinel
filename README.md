# CRYPTO SENTINEL · 加密貨幣即時監控終端

即時市場監控 + 聰明錢流向 + 訂單簿微結構 + 持倉異常 + **鏈上錢包追蹤**，
純前端（零建置、零相依、零金鑰），直接開 `index.html` 或部署到 GitHub Pages 即可使用。

線上版：<https://yuchen0614.github.io/crypto-sentinel/>

---

## 功能

### 1. 全市場掃描（左欄）
- Binance 現貨全部 USDT 交易對（自動濾除穩定幣、槓桿代幣、成交量 < 20 萬美元者），約 380–420 檔。
- 即時價格（WebSocket 推送逐筆閃動）、24H 漲跌、24H 成交金額、**資金動能分數**。
- 資金動能 ＝ 24H 動能 × 週轉率（量/市值，取自 CoinGecko）× 24H 區間位置 × 資金費率偏向。
- 排序（成交量／漲幅／波動／資金動能）、搜尋、僅合約過濾、市場寬度條。
- 鍵盤：`↑` `↓` 切換幣種、`/` 聚焦搜尋。

### 2. 主圖表（中欄）
- Canvas 自繪 K 線（1m/5m/15m/1H/4H），含成交量、**CVD 累積主動買賣差**、VWAP、掛單牆水平線、巨鯨成交標記。
- 十字準線與逐根 K 線浮動資訊；現價線與右側價格刻度依該交易對 tick 精度顯示。
- 統計條：24H 高/低/量/筆數、VWAP、ATR% 波動率、近 15 分鐘主動買賣差、主力成本帶（Volume Profile 重心 ±1σ）。

### 3. 訂單簿追蹤（中欄）
- Binance 深度快照 **1000 檔**（每 2.2 秒）× WebSocket 20 檔即時盤口，合併成買賣階梯與深度條。
- 買賣不平衡度：近端（1–20 檔）＋中段（21–200 檔）的買賣比與偏離。
- 掛單牆：10 檔之後、金額達同側中位數 5 倍且 ≥ 15 萬美元者，顯示價位、距中價距離、佔該側可見流動性比例。
- **疑似假掛單（快閃牆）**：掛單牆若在 45 秒內出現又消失且規模 ≥ 12 萬美元，判定為疑似 spoofing 並發出事件。

### 4. 深度熱圖（中欄）
- 以「距現價的相對距離」為縱軸、時間為橫軸，把每 2.2 秒的快照堆疊成密度熱圖（對數色階）。
- 深度範圍自適應（例如 BTCUSDT 1000 檔約涵蓋中價 ±0.3%），面板會標示實際涵蓋範圍。
- 掛單重心：全部掛單的金額加權重心相對中價的位置。

### 5. 異常事件偵測（中欄）
分級（HIGH / MED / INFO）並自動去重冷卻，涵蓋：
巨鯨連續掃貨/砸盤、成交量異常放大、價格急漲急跌、買賣掛單嚴重失衡、疑似假掛單、
持倉異常堆積、資金費率極端、清算潮（多殺/空軋）、**鏈上大額換幣、多錢包協同買入、大戶倉位變化**。

### 6. 聰明錢壓力計（右欄）
7 項即時指標加權成 0–100 壓力分數與文字結論，並列出每項指標的貢獻值：

| 指標 | 權重 | 資料來源 |
|---|---|---|
| 巨鯨淨流向（5 分鐘） | 20% | 逐筆成交（現貨 + 合約） |
| CVD 累積斜率 | 18% | 逐筆成交主動買賣差 |
| 大戶部位方向 | 18% | Binance 合約 `topLongShortPositionRatio` |
| 訂單簿買賣壓力 | 14% | 深度快照 |
| 槓桿結構（資金費率＋OI 一致性） | 12% | `premiumIndex` + `openInterestHist` |
| 價格動能（VWAP 與短均線） | 10% | K 線 + 逐筆成交 |
| 清算方向壓力 | 8% | Bybit `allLiquidation` |

### 7. 巨鯨即時動向（右欄）
- 逐筆大額成交，門檻預設**自動**（近 10 分鐘成交金額中位數 ×10，最低 8 千美元，因此 BTC 與小幣都合理），
  也可切換 ≥10 萬／≥100 萬美元；顯示時間、方向、價位、數量、金額。
- 1／5／15 分鐘淨流向（大單買 − 大單賣）與方向游標；≥25 萬美元有浮動金額標籤，≥100 萬美元脈衝動畫。

### 8. 持倉結構 · 異常偵測（右欄）
未平倉量與 1H 變化、資金費率與年化、大戶持倉多空比、大戶帳戶比、散戶帳戶比、主動買賣比、OI 走勢圖，
以及自動生成訊號卡：持倉異常堆積、價漲量增、價跌減倉、大戶散戶方向分歧、主動買盤/賣盤背離、資金費率極端。

### 9. 爆倉清算流（右欄）
Bybit 線性合約清算事件（涵蓋成交量前 100 個幣種），近 1 分鐘／15 分鐘金額、多空比與逐筆清單；
1 分鐘內清算 ≥150 萬美元觸發清算潮事件，大額清算會讓面板整片閃光。

### 10. 鏈上聰明錢追蹤（中欄最下方）★
**A. Hyperliquid 大戶錢包即時持倉**
- 追蹤 **52 個真實鏈上大戶錢包**（公開排行榜篩選：帳戶淨值 ≥ 100 萬美元、30 日交易量 ≥ 500 萬美元、
  月 ROI 位於合理區間；取「資金規模最大／月獲利最高／月報酬率最高」三類各一批）。
- 載入時先對名單前 24 檔做**快速預掃**（6 個一批），十幾秒內面板就有內容；之後每 5 秒輪詢 6 個錢包，
  約 45 秒掃完全部。顯示帳戶淨值、**每一個未平倉部位**（幣種、方向、槓桿、數量、名目、進場價、
  清算價、未實現損益、ROE）。
- **倉位變化偵測**：比對前後兩輪持倉，自動產生事件 — 新開倉、加碼、減碼、平倉、**多空翻轉**、未實現損益劇變，
  並彙整所有追蹤錢包的**多空部位總額與多空比**（頂部 HUD 也同步顯示）。
- **大戶最擁擠倉位**：依名目規模排序的主流幣多空分佈（例如 ETH $745.76M / 23 個錢包持有）。
- **多空比給兩種算法**：「名目加權」容易被單一超大型帳戶主導（一筆 $700M 空單就能把整體拉成偏空），
  所以同時顯示「錢包等權（中位數錢包）」，兩者一起看才不會誤判大戶方向。
- 點任一錢包開啟明節：完整持倉表、偵測到的事件、Hyperliquid 區塊瀏覽器連結、一鍵複製地址。

**B. 多鏈 DEX 大額換幣即時流**
- Ethereum / Solana / Base / BNB Chain 熱門池輪詢，抓取鏈上大額 swap（**含發起交易的錢包地址**）。
- 門檻 ≥2 萬 / ≥10 萬 / ≥100 萬美元可切換；顯示時間、鏈、代幣、方向、金額、錢包。
- **聰明錢錢包榜**：把同一錢包的多筆大額交易聚合成畫像並評分
  （交易規模 28% + 買賣方向 16% + **交易後價格變化 36%** + 代幣廣度 20%），
  標籤如「鏈上吸籌主力」「高勝率錢包」「持續派發」「追高型」。
  其中「交易後價格變化」是真實計算：把該錢包每筆大額買/賣的成交價與目前價格比較（只計算 5 分鐘前的交易）。
- **協同買入偵測**：同一代幣 30 分鐘內 ≥3 個不同錢包大額買入 → 發出「多錢包同步買入」事件。
- 聲納雷達：每個錢包有固定方位（地址雜湊），新交易會在雷達上產生漣漪與標籤。

### 11. 動畫與視覺
- 開機：十六進位資料雨 + 六角格線漂移 + 掃描環 + 逐步打勾 + 標題 glitch。
- 背景：星空粒子、透視地板格線、週期掃描光、隨機雜訊條。
- 圖表：K 線由左至右展開、持續掃過的光束、巨鯨標記脈動與漣漪、壓力計**彈簧指針**與弧帶流光、熱圖最新格前緣脈動。
- 訂單簿：價位/數量變動閃光、新檔位滑入、掛單牆掃光漣漪、不平衡條流光。
- 巨鯨與鏈上：列掃光、浮動金額標籤（`+$1.2M` 飄升淡出）、清算面板整片閃光、換幣雷達漣漪。
- 通知：HIGH 等級事件彈出右上角 toast（帶倒數進度條、可點擊關閉）。
- 面板進場階梯、hover 角落標記張開 + 霓虹光暈、數字跳動、狀態列打字游標。
- 已支援 `prefers-reduced-motion`：系統設定減少動態時會自動關閉裝飾性動畫。

## 資料來源（全部為公開端點，無需 API 金鑰）

| 用途 | 端點 |
|---|---|
| 現貨行情、K 線、深度 | `api.binance.com` REST |
| 現貨逐筆成交、20 檔盤口、全市場輕量行情 | `wss://stream.binance.com:9443` |
| 合約統計（資金費率、持倉、大戶多空比、OI） | `fapi.binance.com` REST |
| 合約逐筆成交、清算事件 | `wss://stream.bybit.com/v5/public/linear` |
| 鏈上永續合約錢包持倉 | `api.hyperliquid.xyz/info`（`clearinghouseState`） |
| 鏈上大戶名單 | `stats-data.hyperliquid.xyz/Mainnet/leaderboard`（約 39 MB，只在前端讀取濃縮後的 `data/whales.json`） |
| 鏈上 DEX 熱門池與大額換幣 | `api.geckoterminal.com/api/v2` |
| 市值、週轉率、BTC 市佔 | `api.coingecko.com` |
| 恐懼貪婪指數 | `api.alternative.me` |

### 兩個實測踩到的坑（已在程式中處理）
1. **Binance 合約串流 `fstream.binance.com` 可以完成連線交握，但一則資料都不推送**（靜默封鎖），
   所以合約逐筆成交與清算改用 Bybit 公開串流；合約的資金費率、持倉、大戶多空比仍取自 Binance REST。
   所有串流都有指數退避重連與 90 秒心跳看門狗，現貨串流失敗會自動切到 Bybit 現貨備援。
2. **GeckoTerminal 免費層比文件寫的嚴格**：實測約 5 次請求後連線就被直接丟棄（不是回 429）。
   因此所有 GT 請求走單一佇列、固定 **14 秒間隔**（約 4 次/分），失敗則整條佇列冷卻 90 秒，
   並只在冷卻時於介面顯示「鏈上 API 冷卻中」。每輪輪詢 1 個高流量池，單次呼叫即可帶回該池所有大額成交。

### 大戶名單如何保持更新
`scripts/fetch_whales.py` 下載公開排行榜（4.7 萬名交易者）→ 篩選 → 輸出濃縮的 `data/whales.json`（約 10 KB）。
`.github/workflows/refresh-whales.yml` **每日 02:17 UTC 自動執行並在名單變動時 commit**，Pages 隨之重建；
前端只需要讀取這個小檔案，不必下載 39 MB。

## 版面

單頁三欄儀表板：左側全市場掃描、中間主圖表與訂單簿／熱圖、右側訊號面板，
**鏈上聰明錢區塊固定在頁面下方、全寬常駐**（不需要切換分頁就看得到大戶持倉）。
寬度 1760 / 1500 / 1360 / 1220 / 760 各有對應斷點；高度 1050 / 900 / 800 會自動壓縮圖表與面板密度。

字型：Inter（介面）＋ Space Grotesk（標題）＋ JetBrains Mono（數據），中文走系統 CJK 字；數字全部等寬對齊。

## 本機執行

```bash
python -m http.server 8777
# 開啟 http://127.0.0.1:8777/
```

直接雙擊 `index.html` 也能跑（全部使用傳統 script，沒有 ES module 或 fetch 本機檔案）；
但 `data/whales.json` 需要 http 環境才會載入，用 `file://` 開啟時鏈上大戶區塊會自動略過。
